## How it Works

1. **Configure plugins** using the Suga editor:

   ```bash
   suga edit
   ```

2. **Drag components** into your platform and configure their parameters using this reference

<Info>
Official plugins come with sensible defaults, so customization is optional.
</Info>

## Referencing Plugin Outputs

Plugins can reference outputs from other plugins using template syntax: 

**Example:** 
- `${infra.my-vpc.public_subnets}`
- `${databases.main.connection_string}`
